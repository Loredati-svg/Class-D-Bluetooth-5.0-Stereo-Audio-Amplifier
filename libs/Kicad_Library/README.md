# KiCad Custom Libraries

A collection of custom schematic symbols, PCB footprints, and 3D models for KiCad EDA.

## 📦 Contents

This repository contains custom libraries designed for KiCad projects:

* **Schematic Symbols (`.kicad_sym`)**: Custom component definitions.
* **PCB Footprints (`.pretty` / `.kicad_mod`)**: Custom footprints and package layouts.
* **3D Models (`.3dshapes` / `.step` / `.wrl`)**: 3D CAD models for realistic 3D visualization.
